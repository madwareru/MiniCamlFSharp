# MiniCamlFSharp

Проект порта языка MinCaml с языка OCaml на F#.

## Ключевые особенности
- Этапы с аллокацией регистров и генерацией ассемблера заменены другими, для генерации кода на C
- Вместо парсинга подмножества ML используется упрощённый синтаксис, основанный на S-выражениях
- В проект включена минималистичная библиотека для парсер комбинаторов, на ней реализован парсер для SExpr.
- В проект так же включены реализации определительных интерпретаторов для промежуточных представлений, используемого в языке, этот подход позволяет убедиться в эквивалентности преобразований между проходами компилятора.
- Параллельно с разработкой ведётся вики, где по порядку объясняются все этапы работы компилятора со ссылками на код.
