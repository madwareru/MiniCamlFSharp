# MiniCamlFSharp

Проект комиплятора на языке F#, вдохновлённый проектом языка MinCaml на языке OCaml.

## Ключевые особенности
- Этапы с размещением регистров и генерацией ассемблера заменены другими, для генерации кода на C
- Помимо генерации кода на C, есть так же кодогенератор в C#, так же в планах прямая генерация в .Net IL
- Вместо парсинга подмножества ML используется упрощённый синтаксис, основанный на S-выражениях
- В проект включена минималистичная библиотека для парсер комбинаторов, на ней реализован парсер для SExpr.
- В проект так же включены реализации определительных интерпретаторов для промежуточных представлений, используемых в языке, этот подход позволяет убедиться в эквивалентности преобразований между проходами компилятора.
- Проект индексируется посредством deepwiki, детальное описание принципов работы доступно [по данной ссылке](https://deepwiki.com/madwareru/MiniCamlFSharp)
