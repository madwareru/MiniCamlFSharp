# MiniCamlFSharp

Проект порта языка MinCaml с языка OCaml на F#.

## Ключевые особенности
- Оставлена только поддержка архитектуры x86
- Вместо парсинга подмножества ML используется упрощённый синтаксис, основанный на S-выражениях
- В проект включена минималистичная библиотека для парсер комбинаторов, на ней реализован парсер для SExpr.
- В проект так же включена реализация определительного интерпретатора для промежуточного представления используемого в языке, известного как K-нормальная форма, таким образом позволяет убедиться в эквивалентности преобразований этого представления в процессе оптимизаций.
- Параллельно с разработкой ведётся вики, где изменения объясняются поэтапно в стиле literate progamming.
- В идеале вики должна послужить идеальным подспорьем для записи видеокурса, где в прямом эфире можно разобрать все этапы и написать таким образом реализацию с нуля, не обязательно на F#.
- Вики старается следовать изначальной структуре курса, и является своеобразной рефлексией от чтения исходного кода оригинала, с личными комментариями автора данного проекта.
