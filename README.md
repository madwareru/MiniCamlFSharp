# MiniCamlFSharp

Проект порта языка MinCaml с языка OCaml на F#.

## Ключевые особенности
- Оставлена только поддержка архитектуры x86
- Вместо парсинга подмножества ML используется упрощённый синтаксис, основанный на S-выражениях
- В проект включена минималистичная библиотека для парсер комбинаторов, на ней реализован парсер для SExpr.
- Каждый коммит описывает закончию стадию разработки порта, при этом параллельно ведётся вики, где изменения объясняются подробнее в стиле LITERATE PROGRAMMING. Вики старается следовать изначальной структуре курса, и является своеобразной рефлексией от чтения исходного кода оригинала, с личными комментариями автора данного проекта.
